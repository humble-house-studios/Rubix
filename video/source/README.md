# Drop the record clip here

Upload one video file (mp4 or mov) to this folder from the GitHub app.
The "Video clip" workflow turns it into `video/record.ogv`, and WATCH THE 2.51
plays it on the monitor. The office picks it up on its next build.

Optional, in this folder:
- `trim.txt`: start and end seconds on one line, e.g. `12 31`
- `credit.txt`: one line shown under the video, e.g. `Video: <channel>, used with permission`

Only use a clip you have permission for (the creator said yes, or it's
Creative Commons with credit).
